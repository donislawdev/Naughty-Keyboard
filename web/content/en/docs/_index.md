Naughty Keyboard is two programs over one engine. `nkb-gui` is the palette, a small window that types a value into whatever field has the keyboard, driven by shortcuts. `nkb` is the command line, which lists, prints and checks packs and runs in a script or a pipeline. Neither is a reduced version of the other.
